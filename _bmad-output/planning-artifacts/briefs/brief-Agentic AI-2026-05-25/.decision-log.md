## Decisions

| # | Decision | Rationale | Date |
|---|----------|-----------|------|
| 1 | Tech stack: .NET backend + React frontend | Stated by user as requirement | 2026-05-25 |
| 2 | Book identified by ISBN (shared catalog) | Standard book identifier; avoids duplicates | 2026-05-25 |
| 3 | Per-user UserBook records reference shared ISBN catalog | Clean separation of book metadata vs. reading relationship | 2026-05-25 |
| 4 | 4-state reading machine: Resting → Started → Finished/Abandoned; re-startable | Covers all real reading behaviours | 2026-05-25 |
| 5 | Re-read creates new UserBook record with readingNumber | Full history preserved, no data loss | 2026-05-25 |
| 6 | Action Log pattern for stats (StatusChanged + PagesUpdated with old+new value) | Stats as queries over event history; no denormalization needed | 2026-05-25 |
| 7 | Pages tracked as single current value with stepper input | Simple for MVP; delta stored in action log for period stats | 2026-05-25 |
| 8 | Predefined genre enum (not free text) | Prevents data rot; enables clean stats | 2026-05-25 |
| 9 | Open Library API for book pre-fill on ISBN lookup | Zero-friction book entry; free cover art | 2026-05-25 |
| 10 | JWT/Bearer token auth; email + password + first/last name + DoB at registration | Simple, standard; single registration form | 2026-05-25 |
| 11 | No profile edit page for v1 | Reduces scope; profile set once at registration | 2026-05-25 |
| 12 | No password confirmation field; show/hide toggle instead | Modern UX pattern; reduces friction | 2026-05-25 |
| 13 | No pagination on bookshelf; simple scroll | Appropriate for demo-scale data | 2026-05-25 |

| 15 | Dedicated Stats page retained | Key "wow" moment for BMAD demo | 2026-05-25 |
| 16 | Search IS the add flow (inline result, one button) | Reduces clicks for most common entry action | 2026-05-25 |
| 17 | 👥 X readers count on book cards | Social proof from a single COUNT query | 2026-05-25 |
| 18 | "Your unfinished genre" stat — nudge to finish what you started | Honest, motivating insight from existing data | 2026-05-25 |
| 19 | Update progress popup includes Reading Journal history | Two purposes, one popup; zero extra data | 2026-05-25 |
| 21 | App name: BookTracker | Confirmed by user | 2026-05-25 |
| 22 | Database: PostgreSQL | Stated by user | 2026-05-25 |
| 23 | v1 delivery: runs locally + GitHub repository | Stated by user | 2026-05-25 |
| 24 | Backend: full MVC controllers (no Minimal API), 3-tier architecture with interfaces | Stated by user — architectural clarity is a primary goal | 2026-05-25 |
